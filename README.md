# Hypeforge

Hypeforge is a stream toolkit for Twitch that runs on your PC. Its first tool is a punishment wheel: subs, gifted subs and bits earn viewers spins on a wheel of punishments you choose, shown on stream through an OBS overlay.

## Download

Get **Hypeforge_x.y.z_x64-setup.exe** from the [latest release](https://github.com/TheJohnnyBob/hypeforge-releases/releases/latest) and run it. It works on Windows 10 and 11, installs for your Windows account only, and needs no admin rights.

Windows may say "Windows protected your PC" because the installer isn't code-signed yet: click **More info**, then **Run anyway**.

Once it's installed, Hypeforge keeps itself up to date. It downloads new versions in the background, and you choose when to restart for them, so an update never interrupts a stream.
